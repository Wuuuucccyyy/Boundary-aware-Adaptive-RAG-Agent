# 函数画像适配层实施计划

2026-10-18，按用户授权推进。预计实现和验证约1–2小时，在线小样本对照视API时延而定。

1. 新增独立`function_guard`模块，读取现有5条画像，保留原始标注和依据；不修改前两轮冻结实现。
2. 将画像中可解释的类型、关系和参数条件映射为显式规则。区分满足、冲突、未知、分支不生效，以及文档行为、警告和歧义。推断项不能自动成为可靠硬门槛。
3. 建立16个手工声明预期判断的开发案例，验证未知、类型包含、配对长度、公式分支、参数向量长度、缺失策略与排除项。程序不执行R函数，不用运行结果补写画像。
4. 案例通过后，使用同一函数的相近参数配置建立12个路由小样例。完整画像普通路由与动态边界路由共享画像、输入事实、检查器、候选、预算及生成模型；保留相同结果，不预设动态优越。
5. 离线只作开发验证。小样本正式回答对照使用已授权DeepSeek，共24次调用，不自动重试；记录全部步骤、实际usage、检查次数和时延。冻结协议后运行。

本轮目标是可靠地解释文档约束和调用配置。数据事实由调用方显式提供并记录来源，不自动推断独立性等研究设计假设。画像仍为待审样例，结果不是完整统计有效性或真实分析任务正确率。
