# 第二轮实施计划

2026-10-17，按用户指示将边界研究应用于数据分析与统计建模。

1. 构建统计分析结果与方法卡：效应估计、模型验证、样本/总体统计、缺失处理、预测与诊断。所有数值来自确定性合成数据，保留生成过程。不是现实业务数据，不宣称适用于任意实际分析。
2. 建立条件边界：研究设计、总体、地区、时间版本、数据依赖与缺失机制。画像缺失表示未知；有文档依据的冲突才是负向信息。检索失败不永久修改画像。
3. 共同集合选择器按预期新增有效证据减成本选源，负向风险直接影响效用。比较全库、正向、固定、完整画像普通路由、动态、动态去负向六种方案。
4. 构建10/20/30来源的嵌套快照，保持测试题支持源不变，逐步加入主题相同但条件不同的研究。测试包括必要源1/2/4个和无法完整回答；每条件两次在线重复。共432次模型调用，最大输出700 tokens/次，失败不自动重试。
5. 先本地端到端和必要测试，再冻结并运行DeepSeek正式实验。修正引用格式与评分粒度：采用结构化、可逐字核验的证据摘录；仍披露生成自由文本不经过完整蕴含判断。模型与调用使用用户已授权的CC Switch配置。

估计实现与验证1–2小时，在线运行视API时延而定。无需新增密钥或GPU。原有第一轮源代码和结果保持可复现；新增独立模块。
