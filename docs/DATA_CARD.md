# 示例数据说明

本项目全部知识库、制度、数值和问题均为本项目自行构造，可随代码复制、修改和使用。不是公司内部文件，不含真实员工信息，不应用于实际人事、财务或税务决策。原始研究方向 Word 文档不纳入数据集或 Git 仓库。

数据版本 `2026-10-01` 是合成快照标记，并非真实政策生效日。组织名“星河示例实验室”、税号 `DEMO-TAX-000`、`example.invalid` 邮箱均为虚构占位。期权20%税率等只是测试用公式。

- `boundary_rag/data/documents.json`：25 个短文档，其中 20 个含可核验事实、5 个相邻主题干扰文档。每文档作为一个 chunk，无外部分词/向量依赖。
- `profiles.json`：3 组 P/Q/N，P为能力描述，Q为典型问法，N为当前快照经人工构造核查的任务级缺失。`supports` 绑定文档引用，`boundary_basis` 标记检查范围，版本不匹配会在载入时报错。
- `tasks.json`：19 类任务及规则解析模式，属于系统设计的领域本体，不是测试题金标；对自然问法覆盖有限。
- `experiments/queries.json`：8 个开发问题、40 个测试问题；包含任务、可接受文档集合、可接受源集合及可回答性。只供评测程序使用。

重建命令：`python scripts/build_fixture.py` 和 `python scripts/build_benchmark.py`。这些脚本生成的数据应与提交快照一致。正式实验过程中不要重写数据或根据测试结果调参；扩展请升版本并新建实验目录。

已知偏差：资料、画像、任务本体和问题由同一开发过程产生，存在合成设计偏差。开发/测试只是不同问法，存在同一支持文档重用；不构成文档或时间隔离的研究数据划分。测试有刻意加入的口语化问题和邻域误导，但没有外部标注员独立复核。
