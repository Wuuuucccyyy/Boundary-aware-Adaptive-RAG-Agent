# 预先约定的第一阶段评价协议

正式实验只使用 DeepSeek 在线回答。离线摘录器仅用于开发验证。测试集在首次正式运行前冻结，不根据测试结果修改规则、标签、阈值或评分锚点。

## 数据与冻结设置

- 25 个原创合成文档，3 个库，19 类证据需求；版本 `2026-10-01`。
- 8 个开发问题、40 个测试问题；测试集四类各 10 个。无法完整回答类含 8 个完全无答案、2 个只能部分回答。
- 人工编写的任务金标只在评价模块读取；路由器和检索器不读取测试文件。支持服务台联系方式的 HR/IT 均接受为正确来源。
- 开发集用于冒烟检查，没有进行参数搜索。固定 `lambda=0.55`、每库 BM25 top-2、正向/固定首轮 top-1、最多 3 轮和 9 次库调用、24 次模块调用。
- 所有方法共用规则子任务分析器、BM25、分页去重、证据验证器、真实 DeepSeek 生成器和相同预算。正向/固定在缺证据时同样追加检索，因此并非单轮弱基线。
- 动态方法按未满足任务的增量覆盖贪心选库，正向分与软边界分用于覆盖相同时的排序。初始候选保留所有 3 个库。未知任务探索候选，不永久排除。
- 正式测试每种方法每题重复 2 次，共 320 次问答。随机种子 20261017；问题顺序打乱，方法顺序循环平衡；串行运行、无应用缓存；保留服务端缓存 token 字段。
- 模型来自用户授权的 DeepSeek 配置，运行 manifest 记录精确请求模型；每次响应记录实际返回模型。温度 0、关闭 thinking、最大输出 800 tokens。不对失败请求自动重试。

## 指标与限制

必要源召回按每个可支持子任务是否调用任一合法来源计算，再按题平均。同时报告首轮召回与最终召回。全部无答案题不进入此分母，部分可回答题只计有来源的子任务。

证据召回检查实际取回的支持文档。回答质量代理分检查文档引用和预定义事实锚点；缺少的子任务须明确表达无法确定。部分回答按已知事实和未知声明共同计分。它不等同于人类正确性或完整蕴含判断，也可能因改写、数字写法而误扣分；原始回答全部保留，另做少量人工复核。引用有效率仅表示引用来自验证集合，不能证明所有文字忠实。

回答覆盖率指未表达拒答且生成成功的比例；同时报告这些回答的代理质量和可回答性判断正确率，避免靠拒答获得高分。

成本分开报告：API usage 的实际输入/输出/总 tokens；规则模块的 API tokens 为 0，但其调用、处理文本 proxy 和时间全部计入。proxy 定义为每次模块输入输出 UTF-8 字节数除以 4 向上取整，不是 DeepSeek tokenizer，也不是费用。检索不会调用外部模型。验证器只将支持证据传给生成器，因此宽检索不必然增加实际模型上下文。API 失败且无 usage 时标为未知，不能按零消耗解释。

检索调用、模块调用、轮数为硬上限；模型请求以 UTF-8 字节数+256 的保守输入预留加最大输出做准入控制。文本处理 proxy 上限是每个模块启动前检查，单次输出可能使其略超上限，日志保留真实处理量。时间为协作式截止加网络超时，不是实时系统硬截止。

端到端时间从问题进入 Agent 到返回结果，含路由、验证、生成和计量；不含进程启动、一次性索引构建、结果落盘。报告 p50/p95。串行 API 时延受服务端负载、缓存及网络影响。

按题聚类配对 bootstrap 1000 次，报告 dynamic 减各基线的 95% 区间；重复运行不是独立样本。小型手工合成数据与解析规则共享任务本体，dev/test 是问法划分而非文档/时间独立划分，因此不能宣称自然查询泛化、统计显著的研究结论或论文创新。

失败包含生成故障、自动质量不满分或可回答性误判。任何不利结果都保留。下一阶段再增加自然问题、独立标注、时间/文档隔离、模型验证和正向 top-k 敏感性分析。
